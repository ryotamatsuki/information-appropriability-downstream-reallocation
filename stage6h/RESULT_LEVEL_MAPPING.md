# Stage 6-H Result-Level Mapping

## Frozen result

H-P1 at `q=1`:

- `d(e1+e2)/deta > 0`, and
- `dL/deta > 0`,

for a nonempty open parameter region.

Mechanism-off at `q=0`:

- `E_eta > 0 => L_eta < 0`, so the divergence is impossible.

## Literal predecessor test

No verified paper satisfies R1-R5 all at once in the same model.

## Immediate-corollary test

However, H-P1 itself does not require R1-R5 as a new strategic package once q=1 is imposed. The q=1 game factorizes. The theorem can be restated without Bayesian vocabulary:

> Two independently incentivized agents produce two separable concave outputs. A parameter shifts rewards from task 1 to task 2. If task 2's raw effort response is sufficiently larger but its marginal product is sufficiently lower, total effort rises while total useful output falls.

This result is generic to separable concavity and incentive-induced effort allocation. The posterior/A-optimal structure supplies a particular concave `g(e)=e/(1+e)` but does not create an additional strategic feedback in the proved benchmark.
