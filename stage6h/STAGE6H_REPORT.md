## Decisive immediate-corollary reduction

At q=1, where H-P1 is proved,

`L = 1/(1+e1)+1/(1+e2)`

and

`G = g(e1)+g(e2)`, `g(e)=e/(1+e)`.

The private game factorizes:

`pi_1=b(1-eta)g(e1)-k1e1^2/2`,

`pi_2=b eta g(e2)-k2e2^2/2`.

There is no strategic cross-source term at the theorem benchmark.

Let `x=e2_eta>0` and `y=-e1_eta>0`. H-P1 is simply:

- `x>y` so raw total effort rises, but
- `g'(e2)x < g'(e1)y` so total useful output falls / posterior loss rises.

Because `g'` is decreasing when e2>e1, this interval is a generic diminishing-returns allocation condition. The same theorem survives after replacing the two diagnostic information dimensions by two ordinary separable concave productive tasks.

Therefore the theorem is not protected by information essentiality after full Stage-6 label stripping.
