# Stage 6-H Immediate-Corollary Test

## Question

Even if no prior paper states H-P1 literally, is the theorem an obvious corollary of standard economic results once the frozen q=1 model is written down?

## Exact reduction

At `q=1`:

`L = 1/(1+e1) + 1/(1+e2)`

and

`G = 2-L = g(e1)+g(e2)`, where `g(e)=e/(1+e)`.

Private payoffs are independent:

`pi_1 = b(1-eta)g(e1) - k1 e1^2/2`,

`pi_2 = b eta g(e2) - k2 e2^2/2`.

There is no `e_j` in player i's payoff. Therefore the proved q=1 result is not generated by strategic interaction between information producers.

Let derivatives with respect to eta be `x=e2_eta>0` and `y=-e1_eta>0`. Then:

- total effort rises iff `x>y`;
- useful output falls / posterior loss rises iff `g'(e2)x < g'(e1)y`.

Since `g'` is strictly decreasing, if `e2>e1` then `g'(e2)<g'(e1)`. A nonempty interval

`y < x < [g'(e1)/g'(e2)] y`

exists. This is exactly the H-P1 interval after substituting the equilibrium response coefficients.

Nothing in this derivation requires Bayesian signals. Replace `g(e_i)` by the output from two ordinary productive tasks with diminishing returns and the same theorem survives.

## Established economics mapped to the reduction

- Holmstrom-Milgrom multitasking: task-specific incentives distort allocation of effort across tasks.
- Bond-Gomes: excessive concentration is an allocational inefficiency in multitask agency.
- Bruggen-Moers: distorting incentives can produce more total effort while making effort allocation less congruent.
- Stefan et al.: incentive/ranking changes can increase total effort while reallocating it toward the incentivized task.
- A-optimal / majorization logic: balanced directional inputs have greater value under concave separable benefits / lower trace posterior risk.

## Asymmetry-manufacture test

H-P1 needs first-order asymmetry (`k1 != k2` in the Stage 4 witness) because the symmetric point has zero first-order response of the aggregate. The asymmetry is not mathematically illegitimate, but economically it does all the work needed to make the favored task's raw response larger. Diagnostic diversity only supplies the diminishing-return output metric.

The exact interval is a useful characterization, but it does not reveal a strategic feedback unavailable in generic multitask allocation.

## q=0 defense

The best defense is that q=0 makes H-P1 impossible. This proves that a one-dimensional aggregate cannot reproduce the result. It does **not** prove that information is essential: any two-dimensional separable concave production problem has the same distinction between a single aggregate task and two tasks.

## Verdict

`IMMEDIATE-COROLLARY TEST: FAIL`.

`ASYMMETRY-MANUFACTURE TEST: FAIL FOR MAIN-CONTRIBUTION NOVELTY`.

`INFORMATION-ESSENTIALITY NOVELTY TEST: FAIL`.

The model is information-specific in interpretation, but the only proved headline theorem is not information-specific after full label stripping.
