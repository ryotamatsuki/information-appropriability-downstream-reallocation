# Stage 3-J Generic-Replacement Tests

Binding question: if information objects are replaced by ordinary productive tasks/outputs, can the candidate headline result still be generated?

## A — Rare-Event / Field-Failure Learning

### Information model

Monitoring/exposure changes a state-dependent Poisson likelihood. Event and non-event histories update beliefs, changing the value of future monitoring and adaptation.

### Non-information analogue

Replace failure events by stochastic productive output whose expected flow depends on effort and an unknown productivity parameter.

### Result

The literal Bayesian event/no-event object disappears, so the candidate passes the narrow information-deletion test. However, the strategic logic — agents choose an action that jointly generates current payoff and public information about an unknown environment — is exactly the experimentation architecture. The intended result is therefore not protected from generic strategic-experimentation replacement.

Verdict: `FAIL FOR STAGE-4 SELECTION — KILL — IMMEDIATE COROLLARY`.

## B — Endogenous Customer Selection / Endogenous Sampling

### Information model

A retailer chooses a commercial screening action `c`. This changes the distribution of customer types conditional on purchase. Feedback satisfies a type- and state-dependent likelihood, so the manufacturer must integrate over the selected conditional type distribution when updating its posterior. Product adaptation changes the retailer's continuation payoff, which feeds back into `c`.

### Non-information analogue

Replace purchaser feedback and Bayesian updating by deterministic customer/task output. Let the same screening action change the composition of physical customers/tasks but suppose there is no inference about an unknown state.

### Result

The key object — the selection-dependent likelihood ratio and its effect on posterior adaptation value — vanishes. Any residual price/composition effect is an ordinary demand-screening externality, not the candidate proposition. A valid Stage-4 theorem must be stated as a difference between endogenous-likelihood and fixed-likelihood models, so it cannot survive this replacement by construction unless the proposed theorem was wrongly formulated.

Verdict: `PASS TO STAGE 4`, subject to formal proof that the equilibrium comparative static actually changes when the likelihood is endogenous.

## C — Upstream Attention × Downstream Information Acquisition

### Information model

Downstream information quality/effort and upstream scarce attention determine effective information value, with reciprocal incentives.

### Non-information analogue

Replace information with ordinary project quality `e_i` and receiver processing capacity `a_i`, with output `Q_i(e_i,a_i)`.

### Result

The investment-complementarity/crowding-out logic survives. Worse, the information-specific version of the loop is already directly represented in attention/news-quality theory.

Verdict: `FAIL — KILL — EXACT/WHOLE-GAME PRIOR ART`.

## D — Information Obsolescence / Endogenous Regime Relevance

### Information model

A latent regime determines which historical observations are informative; new acquisition helps infer both the state and whether the data-generating regime changed.

### Non-information analogue

Replace legacy information by depreciating physical capital.

### Result

The Bayesian regime-detection object does not survive literal replacement, so D passes the narrow generic-replacement test. However, a strategic vertical theorem cannot be generated without adding a regime process, refresh/acquisition choice, downstream incentive and upstream continuation action. That violates minimality, while simpler versions are absorbed by changing-environment experimentation.

Verdict: `PASS NARROW INFORMATION TEST / FAIL COMPLEXITY GATE`.

## Canonical conclusion

Only B simultaneously passes the replacement test and remains minimally implementable with plausible whole-game distance from inspected priors.
