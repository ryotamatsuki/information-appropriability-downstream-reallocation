# Stage 4-J Benchmarks

## 1. Fixed-likelihood benchmark with feedback volume preserved

Freeze only feedback composition:

`ell_theta(y;c)=bar_ell_theta(y)`.

Let the resulting conditional Bayes-risk reduction be `bar J>0`. Purchase probability remains `1-c`, so

`I_F(c)=(1-c)bar J`,

`I_F'(c)=-bar J<0`.

Retailer objective:

`Pi_F(c)=c(1-c)+delta*rho*(1-c)bar J`.

Interior FOC:

`1-2c-delta*rho*bar J=0`.

Thus

`c_F*(rho)=[1-delta*rho*bar J]/2`

when `0<delta*rho*bar J<1`; otherwise the lower corner `c=0` can bind.

For every interior solution,

`dc_F*/drho=-delta*bar J/2<0`.

Hence the fixed-likelihood model preserves the feedback-volume channel yet predicts the opposite comparative-static direction from the canonical full model.

## 2. Strategic-feedback-off benchmark

Set `rho=0` while keeping selected-sample learning active for the manufacturer.

Retailer solves

`max c(1-c)`,

so uniquely

`c_0=1/2`.

Thus the positive screening response to adaptation stakes is a vertical-incentive result, not a standalone selection-learning result.

## 3. Information-deletion benchmark

Set

`ell_1(y;c)=ell_0(y;c)`.

Then feedback is uninformative and

`J(c)=I(c)=0`.

Retailer again chooses `c=1/2`.

## 4. Selection-frozen benchmark

Impose

`partial ell_theta(y;c)/partial c=0`

while retaining informative feedback. This exactly recovers the fixed-likelihood benchmark above. Thus benchmark nesting is literal rather than interpretive.

## 5. Purchaser type observed by manufacturer

Suppose `M` observes `z` as well as feedback. For each type `z`, define the nonnegative conditional value of the type-specific binary experiment

`j(z)=kappa*mu^2(1-mu)^2 [p_1(z)-p_0(z)]^2 / [m_z(1-m_z)]`,

where `m_z=mu*p_1(z)+(1-mu)*p_0(z)`.

Because purchase iff `z>=c` and the unconditional type density is one,

`I_obs(c)=integral_c^1 j(z) dz`.

Therefore

`I_obs'(c)=-j(c)<=0`.

So a higher continuation stake cannot induce a positive screening response through information value when customer type is observed: screening only deletes nonnegative additive type-specific information.

### Canonical family

With `mu=1/2` and

`p_0(z)=1/2+t-2tz`,

`p_1(z)=1/2-t+2tz`,

we have

`j(z)=kappa*t^2(2z-1)^2`.

Thus

`I_obs'(c)=-kappa*t^2(2c-1)^2<=0`.

The full-model result `I'(c)>0` for the equilibrium interval `(1/2,2/3)` is therefore impossible once `z` is observed.

## Benchmark interpretation

The key information-specific channel is not irrational bias. The manufacturer understands selection perfectly. What matters is that the latent type is not observed, so the observed review is generated by a mixture experiment whose likelihood itself changes with commercial screening. Observing `z` converts the information value into an additive integral and removes the positive composition effect.
