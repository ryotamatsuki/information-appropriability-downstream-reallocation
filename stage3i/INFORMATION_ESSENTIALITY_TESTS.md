# Stage 3-I — Information Essentiality Tests

## Test protocol

Each candidate is subjected to four tests:

1. **Service-effort replacement:** replace information with ordinary sales/service effort. If the game/result survives unchanged, kill.
2. **Information deletion:** remove the information-specific object. A surviving candidate must lose an equilibrium-relevant arrow or result.
3. **Anti-Xu:** ask whether Xu, Tang, Lin & Lu (2022)-type dual-channel free riding can reproduce the result by parameter/preference/contract changes alone.
4. **Benchmark removal:** switch off the proposed information-specific mechanism and require the headline result to disappear or materially change.

## A — Persistent reusable information stock

- Service-effort replacement: **FAIL**. A persistent service/customer-capital stock can reproduce the state-investment logic.
- Information deletion: a state disappears, but only generic dynamic investment remains.
- Anti-Xu: nominally passes because Xu is static, but dynamic service carry-over models defeat information essentiality.
- Benchmark removal: setting persistence to zero removes history dependence but not a distinct information theorem.
- Verdict: `KILL — GENERIC EFFORT / DYNAMIC INVESTMENT`.

## B — Endogenous upstream adoption

- Service-effort replacement: **FAIL/PARTIAL**. A manufacturer can strategically adopt/use a retailer's generic costly investment or service technology.
- Information deletion: adoption stage remains meaningful with generic investment, so information is not essential to the basic loop.
- Anti-Xu: passes Xu narrowly, but Hu et al. and vertical quality/information models already contain the information-to-upstream-action loop.
- Benchmark removal: fixing adoption at one eliminates threshold feedback, showing adoption is doing work, but not uniquely informational work.
- Verdict: `KILL — PRIOR ART / INFORMATION NOT ESSENTIAL ENOUGH`.

## C — Ownership/access rights

- Service-effort replacement: **PASS** in a narrow sense because nonrival informational access can differ from contemporaneous service.
- Information deletion: residual-control/access object disappears.
- Anti-Xu: **PASS**; Xu lacks an information asset/right.
- Benchmark removal: free automatic access removes the ownership mechanism.
- Fatal issue: closest data/property-rights models already contain the investment/use feedback.
- Verdict: `KILL — PRIOR ART`.

## D — Portability

- Service-effort replacement: **PASS** if portability applies to an accumulated informational asset rather than current service.
- Information deletion: inter-firm transferability disappears.
- Anti-Xu: **PASS**.
- Benchmark removal: no portability or automatic portability changes continuation use and collection incentives.
- Fatal issue: Li–Zhang (2026) directly solves portability -> ex-ante collection incentives.
- Verdict: `KILL — PRIOR ART`.

## E — Acquisition versus disclosure

- Service-effort replacement: **PASS**. Ordinary effort has no signal-content disclosure decision.
- Information deletion: acquisition/disclosure stages disappear.
- Anti-Xu: **PASS**.
- Benchmark removal: mandatory/full disclosure eliminates the strategic sharing margin.
- Fatal issue: the acquisition/sharing interaction is already central in Guo–Iyer and newer vertical/horizontal sharing models.
- Verdict: `KILL — PRIOR ART`.

## F — Bayesian precision

- Service-effort replacement: **PASS**. Signal precision/posterior updating cannot be represented by scalar contemporaneous service without changing the game.
- Information deletion: posterior and upstream inference disappear.
- Anti-Xu: **PASS**.
- Benchmark removal: known deterministic state eliminates precision value.
- Fatal issue: precision acquisition plus downstream/upstream response is a mature information-acquisition architecture; no new reallocation interaction was isolated.
- Verdict: `KILL — PRIOR ART`.

## G — Competing information producers

- Service-effort replacement: **PARTIAL PASS** only if information aggregation/correlation matters; otherwise FAIL as a two-effort game.
- Information deletion: multiple effort providers survive unless the aggregation structure is essential.
- Anti-Xu: **PASS** only after adding signal aggregation/correlation.
- Benchmark removal: perfect redundancy collapses the information-aggregation effect.
- Fatal issue: the only distinctive surviving feature is heterogeneous diagnostic content, which is H; multiple producers by themselves are already covered by acquisition/sharing/network literatures.
- Verdict: `KILL — CLOSE PRIOR / DUPLICATES H`.

## H — Diagnostic / informational diversity

### Full object

`theta in R^K`, downstream signals

`y_i = h_i' theta + epsilon_i`,

and posterior precision

`P = Sigma_0^{-1} + sum_i tau_i h_i h_i'`.

### Service-effort replacement

**PASS.**

Replacing `y_i` with ordinary service effort removes:

- the unknown multidimensional state;
- Bayesian posterior updating;
- signal loadings `h_i`;
- covariance/correlation/rank;
- diagnostic redundancy/complementarity;
- the upstream design action conditional on a posterior.

The resulting service game is strategically different.

### Information deletion

**PASS.**

Deleting the information object removes the arrow

`source composition -> posterior geometry -> upstream design response`.

The manufacturer no longer has a Bayesian design problem, and the conjectured diversity/concentration propositions cease to exist.

### Anti-Xu

**PASS.**

Xu-type free riding can change how much effort-created demand is allocated to each route, but it has no multidimensional latent state, signal loading/correlation, posterior precision matrix or Bayesian upstream design response. It cannot generate a result in which equal total information effort has different value solely because the diagnostic directions are redundant versus complementary without adding the H information structure.

### Benchmark removal

**PASS as a Stage 3 conjecture.**

Set `h_1 = h_2` (or reduce the state to one scalar dimension). Diagnostic diversity is switched off. The Stage 4 headline result must disappear or materially shrink under this restriction.

### Verdict

`PREFERRED`.

H survives all information-essentiality tests and is authorized for one minimal Stage 4 model only.

## I — Post-exit reuse

- Service-effort replacement: **FAIL/PARTIAL**. Relationship-specific investment can have post-separation continuation/hold-up value.
- Information deletion: persistent informational asset disappears, but generic specific-investment logic remains.
- Anti-Xu: **PASS** narrowly.
- Benchmark removal: no post-exit use removes continuation wedge.
- Fatal issue: Wang–Wang (2026) directly treats post-exit continuity of a learning asset; standard hold-up logic also absorbs much of the mechanism.
- Verdict: `KILL — PRIOR ART / GENERIC SPECIFIC INVESTMENT`.

## J — Retention for learning option value

- Service-effort replacement: **PASS** if retention is valuable because it preserves future informative experimentation under uncertainty, not because it preserves current service.
- Information deletion: future signal-arrival option disappears, changing the retention/stopping problem.
- Anti-Xu: **PASS**.
- Benchmark removal: known state or zero future information arrival removes the learning option.
- Remaining threat: strategic experimentation with endogenous organization/membership is a close literature; the vertical downstream-retention implementation has not yet been shown to generate a distinct theorem.
- Verdict: `TOP 3 — RUNNER-UP`, not preferred.

## Summary

Information-essentiality survivors before whole-game ranking: **C, D, E, F, H, J** (with G only conditional on folding into H).

After prior-art hard kill: **H and J** remain.

Preferred: **H**.

The Stage 4 authorization is deliberately narrow: diagnostic diversity only. No simultaneous dynamics, ownership, portability, disclosure, bargaining or contracts are authorized.
