# Stage 3-I — TOP Candidates Deep Dive

Only two candidates are promoted. The Stage 3 template permits at most TOP 3; it does not require three. A third candidate is intentionally omitted because the next-best candidate G is not a distinct mechanism family once its informational-content feature is isolated from generic multiple-effort competition.

# TOP 1 / PREFERRED — H: Diagnostic Diversity under Downstream Concentration

## Mechanism

Downstream nodes do not merely produce more or less of a scalar informational input. They observe different diagnostic directions of a multidimensional upstream product/problem state. Reallocation changes the composition of the signal portfolio and therefore the posterior geometry faced by the upstream producer.

## Minimal players

- `M`: upstream manufacturer/product designer.
- `S_1`, `S_2`: downstream field/service/customer-facing nodes that can invest in generating diagnostic information.

No additional firms or consumers are strategic in the minimal game.

## Minimal information structure

`theta in R^2`, with prior

`theta ~ N(0, Sigma_0)`.

Node `i` produces

`y_i = h_i' theta + epsilon_i`,

where noise precision is

`tau_i = nu_i(eta) e_i`

in the first minimal specification, with `e_i >= 0` and `nu_i(eta)>0` mapping local downstream activity/exposure into diagnostic observations.

Posterior precision:

`P(e,eta) = Sigma_0^{-1} + sum_i tau_i h_i h_i'`.

The manufacturer observes signals and chooses

`a = E[theta | y_1,y_2]`

under quadratic design loss.

Expected residual design loss is proportional to

`L(e,eta) = tr(P(e,eta)^{-1})`.

## Information-production cost

Use the minimal convex form

`C_i(e_i)=k_i e_i^2/2`.

## Private payoff skeleton

Each node captures only a route-weighted fraction of expected product-fit improvement generated by the information portfolio:

`pi_i = b_i w_i(eta) [L_0 - L(e,eta)] - C_i(e_i)`

or the closest algebraically simpler normalization that preserves the same strategic feedback.

Stage 4 may modify this normalization only to make the minimal model solvable; it may not add another strategic mechanism.

## System benchmark

System value places the full relevant economic value on product-fit improvement:

`W = B(eta)[L_0-L(e,eta)] - sum_i C_i(e_i) + commercial terms not depending on e`

with the smallest possible set of route weights required to define the reallocation experiment.

## New strategic-feedback loop

`eta -> local source exposure/appropriation -> {e_1,e_2} -> posterior precision matrix P -> upstream design accuracy -> private returns -> {e_1,e_2}`.

The novelty candidate is the interaction between reallocation-driven private incentives and posterior geometry.

## Information-essentiality

The value of source `i` depends on

`-d tr(P^{-1})/d tau_i = h_i' P^{-2} h_i`.

Thus value depends on what the source diagnoses relative to what is already known, not only how many units of effort or sales it generates.

A scalar sales/service effort cannot reproduce this without adding a multidimensional information structure.

## Closest prior threats

1. Xiong, Li & Lang (2025), *Games and Economic Behavior*: correlated information from networked consumers and optimal information targeting.
2. Myatt & Wallace (2019), *Journal of Economic Theory*: costly heterogeneous/correlated signals acquired by networked strategic players.
3. Migrow & Squintani (2023), *JPE Micro*: correlated information acquisition and sharing in organizations.
4. Board & Meyer-ter-Vehn (2024), *AER*: network structure and experimentation/information crowd-out.

Stage 4 must compare the solved model against these full games, not merely mention them as related work.

## Candidate propositions to hard-kill

### H-P1 — Volume/diversity divergence

There exists an admissible region in which downstream reallocation toward one node raises aggregate information effort or raw signal volume but worsens expected upstream design accuracy because diagnostic coverage becomes more redundant.

### H-P2 — Diagnostic retention value

A commercially small downstream node can have positive system retention value because it supplies a sufficiently distinct diagnostic direction even when its standalone commercial contribution is below its retention cost. The diagnostic retention region collapses when signals become collinear.

### H-P3 — Redundancy threshold

The welfare effect of downstream concentration changes with diagnostic redundancy/correlation: concentration becomes less costly as sources become more redundant and can reverse ranking relative to a sufficiently complementary-source region.

These are conjectures, not Stage 3 proofs.

## Mechanism-off benchmark

Set

`h_1 = h_2`

and normalize to a scalar-state/redundant-signal benchmark.

This removes diagnostic diversity while preserving two downstream effort providers and reallocation/free-riding incentives.

## Stage 4 primary kill test

**KILL H** if any claimed H-P1/H-P2/H-P3 result survives essentially unchanged in the collinear benchmark, or can be reproduced by a scalar Xu-type costly-effort/free-riding model without posterior geometry.

## Empirical distinguishing implication

Holding aggregate downstream sales/contact volume approximately fixed, concentration should damage product-learning outcomes more when surviving and disappearing nodes historically generate less-correlated failure modes/customer-use cases; the effect should be weak when their feedback is redundant.

# TOP 2 / Runner-up — J: Retention for Learning Option Value

## Mechanism

A downstream node is retained not for current commercial output alone but because future uncertain product/customer states can make the node an informative experiment. Retention preserves a future learning option.

## Minimal skeleton

- `M` chooses retain/close `r in {0,1}`.
- if retained, a future state is realized and the node can generate a signal at a cost;
- `M` updates and adapts product/design/operations;
- continuation value determines the initial retention choice.

## Information-specific object

An option to receive a future signal before choosing an adaptive action.

## Service-effort replacement

Passes only when the value of retention arises from uncertainty resolution; replacing learning with deterministic service destroys the option-value problem.

## Closest threats

- Board & Meyer-ter-Vehn (2024), strategic experimentation in networks.
- Gieczewski & Kosterina (2024), experimentation with endogenous organizational membership/exit.

## Candidate result

A node with negative static commercial surplus may optimally be retained because its future signal option changes state-contingent adaptation, with retention value increasing in the variance of strategically relevant states only over an interior region.

## Primary kill test

If the retention rule is equivalent to adding an exogenous continuation benefit or is a direct application of existing endogenous-organization experimentation results, kill J.

## Why J loses to H

J needs at least three linked additions relative to the failed static model: uncertainty, dynamics, and a retention/stopping decision. H requires only one new formal object—the multidimensional diagnostic information structure—while retaining a static two-node game. J therefore has higher complexity and prior-art risk.

# No third promotion

Candidate G would become a third option only by emphasizing heterogeneous/correlated signal content. Once that content is made essential, G is the H mechanism. Without it, G is a standard multiple-agent information-acquisition/free-riding architecture. Promoting it separately would violate the requirement to compare genuinely different mechanisms.

# Selection

`H — PREFERRED`

`J — TOP 3 / RUNNER-UP`

All other candidates — `KILL`.
