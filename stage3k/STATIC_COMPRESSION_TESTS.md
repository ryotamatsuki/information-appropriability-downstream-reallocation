# Static / Dynamic Compression Tests

The binding question is whether the information side can be summarized by a scalar continuation value or induced transition, leaving an ordinary decision problem.

| Candidate | Compression attempt | Result | Verdict |
|---|---|---|---|
| K1 | replace allocator by posterior/score-contingent prize function | exact reduced contest remains | FAIL |
| K2 | communication strategy and receiver response remain jointly strategic | no scalar compression without destroying reporting game | PASS compression gate; prior-art kill |
| K3 | substitute downstream BR `e*(a,mu)` into signal/transition and Bellman value | one-agent controlled experiment remains | FAIL |
| K4 | substitute participation/data response into dynamic transition | reduced data-feedback dynamic remains | FAIL |
| K5 | dynamic delegation/learning keeps agent private learning and principal policy jointly strategic | compression changes game | PASS; prior-art kill |
| K6 | substitute downstream effort response into organization-contingent transition | upstream dynamic organization problem remains | FAIL in minimal architecture |
| K7 | encode future allocation as prize rule / contest continuation value | experiment contest remains | FAIL |
| K8 | expert advice and client implementation jointly determine whether/precision of testing | cannot compress without changing exposure game | PASS; prior-art kill |

## K3

The minimal architecture is vulnerable to

`V_M(mu)=max_a {u_M(a,mu)+delta E[V_M(mu')|a,e*(a,mu)]}`.

After substituting the downstream best response, the second strategic player disappears from the equilibrium system. This is exactly the kind of reduction Stage 3-K prohibits.

## K6

Likewise, in the minimal architecture

`e*=B_R(mu,d)`

can be substituted into the posterior/capability transition. The upstream organization chooser then solves a dynamic decision problem over `d`. A non-compressible version would require, for example, a genuine commitment or private-rent interaction across future organizational choices. That would be an additional economic primitive, not a clarification of the existing candidate.

## K2/K5/K8

These candidates pass the compression gate because communication/delegation/reputation strategies cannot be represented by a single scalar value without eliminating an equilibrium response. But they are not Stage 4 candidates because close prior literature already studies essentially those strategic architectures.
