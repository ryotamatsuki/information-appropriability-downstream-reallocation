# Player Essentiality Tests

A player is strategically essential only if deleting that player, solving out its action, or replacing it with an equivalent reduced-form technology destroys the intended headline theorem.

| Candidate | Player removed / solved out | Reduced game | Same theorem class? | Verdict |
|---|---|---|---:|---|
| K1 | upstream allocator | contest with exogenous prize schedule | YES | FAIL |
| K2 | receiver/allocator | sender reputation problem changes materially | NO | PASS PLAYER GATE, but prior-art kill |
| K3 | downstream information producer | upstream controlled-sensing technology after substituting `e*(a,mu)` | YES in minimal model | FAIL |
| K4 | intermediary/participants | reduced-form data-generation transition | YES in minimal architecture | FAIL |
| K5 | principal or agent | delegation/communication game collapses | NO | PASS PLAYER GATE, but prior-art kill |
| K6 | downstream intermediary | upstream organization problem with induced information/capability transition | YES absent an extra dynamic commitment primitive | FAIL |
| K7 | principal allocator | dynamic contest with prize rule | YES | FAIL |
| K8 | client/decision maker | reputation test process changes | NO | PASS PLAYER GATE, but prior-art kill |

## K1

The allocator's posterior-based business decision can be summarized as a prize function of observed performance/posterior. Once the schedule is fixed, the strategic content resides in the agents' effort contest. Removing the allocator changes interpretation rather than the core comparative static.

## K3

The downstream producer chooses `e` after observing upstream action `a`. In the minimal candidate, solve

`e* = B_S(a,mu)`

and substitute it into the signal/transition technology. The upstream player then faces a controlled experiment with induced informativeness. The candidate did not identify a theorem that requires the downstream player to retain an independent reaction function after this substitution.

## K4

Participation/data-generation responses can be represented by an induced transition from upstream action to future data. Without an additional strategic commitment or private-information margin, the intermediary is not theorem-essential.

## K6

This was the most important player-removal test. A richer dynamic contract could make the downstream intermediary indispensable, because effort today would depend on anticipated future organization and rents. But that commitment/contracting friction is not part of the one-object Stage 3-K candidate. In the minimal architecture, the intermediary's effort response can be embedded in the transition technology faced by the upstream organization chooser. Adding a contracting friction solely to pass this gate would be feature accumulation.

## K7

The central rent-allocation rule can be represented as a contest prize schedule. The key experiment-effort interactions remain among the competing agents, so the upstream allocator is not essential to the proposed theorem.

## Passing-but-killed candidates

K2, K5, and K8 can have genuinely indispensable strategic players. They fail for a different reason: the relevant information/communication/delegation/reputation game families are already mature and contain very close full strategic loops.
