# Canonical Results

## Lemma 1 — Private information effort under downstream reallocation

Private FOC:

`Φ_P = m_S ω_S(η) D_S'(x) g'(e) - C'(e) = 0`.

If `Φ_{P,e}<0`, then by the Implicit Function Theorem,

`de^P/dη = -[m_S ω_S'(η) D_S'(x) g'(e)] / Φ_{P,e}`.

Hence `ω_S'(η)<0` implies

**`de^P/dη < 0`.**

## Theorem 1 — Information-Incentive Divergence under Downstream Reallocation

Suppose:

1. the information producer's downstream footprint shrinks (`ω_S'<0`);
2. information effort is noncontractible and returns are incompletely appropriable;
3. product-improvement information is reusable through both routes (`D_S',D_R'>0`);
4. the effort problems have unique interior concave optima; and
5. the weighted marginal system return in the expanding route satisfies

`A_R ω_R'(η) D_R'(x) > - A_S ω_S'(η) D_S'(x)`.  **(G)**

Then downstream reallocation implies

**`de^P/dη < 0 < de^C/dη`.**

Interpretation: the node producing information loses appropriable own-route return while the system increasingly values the same reusable information through the expanding route.

## Corollary 1 — Cross-route use is necessary for the positive coordinated response

Within the canonical separable model, if the expanding route receives no product-improvement benefit (`D_R'=0`), then the coordinated comparative static is negative rather than positive. Cross-route usability is therefore necessary for the P3 sign reversal in this model class.

## Corollary 2 — One-for-one route reallocation

If `ω_R'=-ω_S'>0` and `D_R'=D_S'`, condition (G) reduces to

**`A_R > A_S`.**

This is an economic interpretation, not a separate main contribution.

## Welfare benchmark results

In the frozen quasilinear benchmark:

**`e^P < e^C < e^W`**,

and both `e^C-e^P` and `e^W-e^P` widen as `η` shifts activity toward the lower-cost route.

## Supporting organizational result

Conditional on an interior private retention threshold and the verified Stage-7 continuity conditions, there is a local region on the private non-retention side in which social welfare still favors retaining the information-producing downstream capacity.
