# Rollback Map

| Proposed or discovered change | Earliest stage to revisit |
|---|---|
| Algebra/proof failure in the core model | Stage 4 or Stage 7, depending on affected formulation |
| New mechanism needed to rescue result | Stage 3 / Stage 4 |
| Main theorem materially changes | Stage 4, then Stage 6 novelty re-kill |
| Novelty boundary / closest-literature distinction changes | Stage 6 |
| Generality or welfare logic changes | Stage 7 |
| Full-paper investment rationale collapses | Stage 7.5 |
| P4 is proposed for revival | Stage 7 plus Stage 6 as required |
| Stage-2 RRC mechanism proposed for revival | Stage 2 / Stage 3; cannot be silently restored |
| Only notation/prose/order changes | Editorial; no rollback if economics unchanged |

All substantive changes require a theory-change record and downstream gates to be re-run.
